# Verified Curation Source Baseline — 2026-08-18

NorthStar’s staged resource expansion uses authoritative primary sources only. The [CNCF graduated and incubating projects registry](https://www.cncf.io/projects/) presents its governed project set with explicit cloud-native functional classifications, including observability, security and compliance, orchestration, storage, networking, service mesh, CI/CD, messaging, and API gateway categories. It is suitable for identifying official project candidates and cross-checking ecosystem vocabulary.

GitHub’s [repository REST API documentation](https://docs.github.com/en/rest/repos/repos?apiVersion=2026-03-10) documents public repository metadata endpoints and organization repository listings. For a curated project whose official repository is known, the API can supply the canonical repository URL, official description, homepage, repository-declared license, and repository topics. NorthStar will treat these values as source evidence, not as a publication decision.

The curation workflow will retain each source URL and will not infer category, pricing, tags, relationship, or logo fields where the relevant primary source does not establish them. Human moderation remains required for public approval.
