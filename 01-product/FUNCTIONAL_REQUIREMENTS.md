# NorthStar Functional Requirements

## Resource Management

- Create resource
- Read resource
- Update resource through controlled workflows
- Archive resource
- Verify resource
- Report resource
- Detect duplicates
- Track source and freshness

## Classification

- Categories
- Subcategories
- Tags
- Resource types
- Pricing metadata when available

## Relationships

Support at minimum:
- Alternative To
- Similar To
- Competitor Of
- Integrates With
- Built By
- Maintained By
- Used By
- Funded By
- Part Of
- Depends On

## Community

- Submission
- Suggestions
- Reports
- Voting
- Collections
- Bookmarks
- Profiles

## Search

- Full-text search
- Fuzzy matching
- Facets
- Filters
- Relationship-aware discovery
- Semantic search readiness

## Authentication

Support:
- Social login
- Google
- GitHub
- Email
- Magic link

Exact identity-provider implementation is TBD.

## External Data

The project direction is to support all relevant external data sources. Exact source list, legal basis, ingestion frequency, and provider-specific constraints require separate validation.
