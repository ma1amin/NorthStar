# NorthStar User Journeys

## Discovery

1. User opens NorthStar.
2. User searches or browses a category.
3. User filters results.
4. User opens a resource.
5. User explores alternatives, similarities, integrations, and ecosystem relationships.
6. User bookmarks or adds the resource to a collection.

## Contribution

1. User submits a URL.
2. System extracts available metadata.
3. System checks for duplicates.
4. System suggests classification and relationships.
5. User reviews the proposed data.
6. Submission enters moderation where required.
7. Approved resource becomes discoverable.

## Correction

1. User identifies inaccurate data.
2. User suggests an edit.
3. System records the proposed change.
4. Moderator or approved workflow validates it.
5. Change is applied with an audit trail.

## Onboarding

The onboarding process must be short and optional for public browsing. Exact onboarding screens remain an open UX decision.
