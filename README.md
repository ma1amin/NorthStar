NorthStar is an open-source, community-driven resource intelligence and discovery platform. It is designed to transform scattered digital-resource discoveries into structured, searchable, interconnected knowledge.

## Documentation Status

This package is the initial full documentation foundation for NorthStar. It is based only on the project information supplied by the project owner and the two uploaded project-initiation documents.

Undecided items are explicitly marked **TBD**. Recommendations are clearly labeled as recommendations and must not be treated as final project decisions.

## Current Confirmed Direction

- Global from day one
- Fully bilingual: English and Arabic
- Public browsing without mandatory registration
- Community-driven
- Open-source
- Knowledge-graph-oriented
- Full feature ambition, with MVP sequencing to be refined
- Approved technology stack is provisional and may be adjusted as project needs evolve
- All relevant external data sources are intended to be considered
- Authentication should support social login, Google, GitHub, email, and magic links
