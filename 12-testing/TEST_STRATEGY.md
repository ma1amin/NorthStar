# NorthStar Test Strategy

## Unit

Test:
- domain rules
- classification
- duplicate detection
- relationship validation

## Integration

Test:
- database
- search indexing
- authentication
- external-source adapters
- AI adapter

## End-to-End

Test:
- search
- resource submission
- moderation
- authentication
- collections
- bookmarks
- relationship exploration

## Bilingual

Critical journeys must be tested in both English and Arabic, including RTL behavior.
