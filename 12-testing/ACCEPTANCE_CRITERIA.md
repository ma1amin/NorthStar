# NorthStar Acceptance Criteria

## Discovery

- User can search resources.
- User can filter results.
- User can open a resource.
- User can navigate to related resources.

## Contribution

- User can submit a resource.
- Duplicate detection runs.
- Moderation workflow works.

## Knowledge Graph

- Relationships are stored.
- Relationship types are validated.
- Related resources can be discovered.

## Internationalization

- English and Arabic are available.
- RTL layout works correctly.
- Switching language preserves user context where practical.
