# NorthStar Observability

Track:

## Application
- request latency
- error rate
- throughput
- queue depth

## Search
- latency
- zero-result searches
- index freshness
- search errors

## Graph
- traversal latency
- relationship query volume
- projection lag if a graph read model is introduced

## Ingestion
- source health
- job success/failure
- freshness
- duplicate rate

## Business
- submissions
- approvals
- active contributors
- resource views
- bookmarks
- search success
