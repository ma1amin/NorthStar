# NorthStar User Stories

## Discovery

- As a visitor, I want to search resources so I can find something useful quickly.
- As a visitor, I want to browse categories so I can discover resources without knowing their names.
- As a user, I want to see related resources so I can understand alternatives and adjacent tools.

## Contribution

- As a contributor, I want to submit a resource with minimal effort.
- As a contributor, I want the system to detect duplicates before submission.
- As a contributor, I want to suggest relationships between resources.

## Curation

- As a moderator, I want to review submissions.
- As a moderator, I want to merge duplicates.
- As a moderator, I want an audit trail for important changes.

## Personalization

- As a user, I want to bookmark resources.
- As a user, I want to create collections.

## Bilingual Use

- As an English-speaking user, I want the full product experience in English.
- As an Arabic-speaking user, I want the full product experience in Arabic.
- As a bilingual user, I want language switching without losing context.
