# NorthStar Product Specification

## Vision

NorthStar is an open-source intelligence and discovery platform for digital resources. It helps users collect, organize, discover, connect, preserve, and explore valuable resources through a structured and searchable knowledge graph.

## Problem

Valuable resources are continuously shared through messaging groups, communities, social platforms, repositories, newsletters, and other channels. Over time, people lose the context needed to find those resources again.

The platform addresses fragmented discovery and repeated discovery effort.

## Mission

Transform scattered discoveries into structured, searchable, interconnected knowledge.

## Core Objectives

1. Create a searchable knowledge database.
2. Enable intelligent resource discovery.
3. Support community contributions.
4. Prevent duplicate entries.
5. Store rich metadata.
6. Support advanced filtering.
7. Remain fully open source.
8. Allow public access without mandatory registration.
9. Provide a frictionless onboarding experience.
10. Build a relationship-based knowledge graph.
11. Preserve knowledge that would otherwise disappear in community history.
12. Enable exploration through connections rather than only search.

## Initial Resource Types

- GitHub Repositories
- AI Platforms
- Developer Tools
- Cybersecurity Tools
- Design Resources
- SaaS Products
- Accelerators
- Incubators
- Learning Platforms
- Research Platforms
- Open Source Projects

The architecture must remain category-agnostic.

## Core Capabilities

- Resource directory
- Search and filtering
- Rich resource pages
- Resource submission
- Duplicate detection
- Moderation
- Relationships
- Collections
- Voting
- Bookmarks
- User profiles
- External-source ingestion
- AI-assisted enrichment
- Analytics
- API

## Product Boundaries

NorthStar should not become a generic social network. Community features should support resource knowledge and discovery.

NorthStar should not depend on a single external provider for core functionality.

## MVP Direction

The owner requested all major features. The exact MVP cut is still an open product decision. Recommended sequencing is documented in `MVP.md`.
