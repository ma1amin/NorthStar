# NorthStar MVP

## Confirmed Direction

The owner wants all major features considered. This document proposes sequencing rather than removing features.

## Must Have

- Public resource directory
- Resource detail pages
- Categories
- Tags
- Search
- Advanced filters
- Resource submission
- Duplicate detection
- Moderation
- Core relationships
- English/Arabic interface
- Public browsing
- Authentication
- Basic user profile
- Basic collections
- Basic bookmarks
- Basic API foundation

## Should Have

- Voting
- Reputation
- Automated metadata extraction
- External-source ingestion
- Resource freshness checks
- Relationship suggestions
- Resource comparison
- Trending resources

## Could Have

- Visual graph explorer
- AI resource assistant
- Semantic search
- Advanced recommendation engine
- Browser extension
- Community bots

## Future

- Deeper ecosystem intelligence
- Advanced graph analytics
- Additional ingestion channels
- Expanded integrations
- Unique monetization model

These classifications are recommendations, not confirmed product decisions.
