# Taxonomy and Tagging Strategy

## Principle

Categories should provide stable structure. Tags should provide flexible descriptors.

## Initial Areas

- AI
- Development
- Cybersecurity
- Design
- SaaS
- Startups
- Research
- Learning
- Open Source

These reflect the project direction and should be refined through real resource data.

## Rules

- Avoid duplicate concepts across category and tag layers.
- Keep taxonomy understandable.
- Support aliases and localization.
- Track taxonomy changes.
