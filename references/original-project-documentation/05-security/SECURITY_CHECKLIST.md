# NorthStar Security Checklist

## Identity
- [ ] MFA strategy evaluated
- [ ] Session management defined
- [ ] OAuth redirect validation
- [ ] Magic-link expiry defined

## Application
- [ ] Input validation
- [ ] Output encoding
- [ ] CSRF strategy
- [ ] Rate limiting
- [ ] Abuse detection

## Data
- [ ] Encryption at rest strategy
- [ ] Encryption in transit
- [ ] Backup strategy
- [ ] Data retention policy

## Operations
- [ ] Secrets management
- [ ] Dependency scanning
- [ ] Security logging
- [ ] Incident response

All unchecked items are implementation work, not claims of current compliance.
