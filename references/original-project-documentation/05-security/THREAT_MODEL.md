# NorthStar Threat Model

## Assets

- User accounts
- Resource data
- Relationship data
- Moderation decisions
- API credentials
- External-source credentials
- Private collections
- Audit records

## Threats

- Account takeover
- Spam
- Malicious submissions
- Stored XSS
- API abuse
- Credential theft
- Data poisoning
- Relationship manipulation
- Scraper abuse
- Supply-chain vulnerabilities

## Priority

Protect account integrity, data integrity, moderation integrity, and external integration credentials.
