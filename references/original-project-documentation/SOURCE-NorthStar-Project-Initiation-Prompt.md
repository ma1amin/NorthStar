# NorthStar - Project Initiation Prompt

You are acting as a Senior Product Architect, Solution Architect, UX Strategist, Knowledge Graph Specialist, and Open Source Platform Designer.

Your task is to design and plan a new platform called **NorthStar**.

NorthStar is an open-source, community-driven platform that helps users discover, organize, preserve, search, and connect valuable digital resources through a structured knowledge graph.

The platform is NOT a simple directory of links.

It is a knowledge platform where resources become interconnected entities enriched with metadata, relationships, community signals, and intelligent discovery mechanisms.

---

## Background

Professionals continuously discover valuable resources through:

- WhatsApp Groups
- Telegram Channels
- Discord Communities
- Slack Workspaces
- LinkedIn Posts
- GitHub Repositories
- Newsletters
- Online Communities

Over time these discoveries become difficult to find again.

NorthStar aims to solve this problem by creating a permanent, searchable, community-maintained knowledge repository.

---

## Core Resource Types

Initially support:

- GitHub Repositories
- AI Platforms
- Developer Tools
- Cybersecurity Tools
- Design Resources
- SaaS Platforms
- Startup Accelerators
- Incubators
- Research Platforms
- Learning Resources
- Open Source Projects

Architecture must remain flexible for future categories.

---

## Core Objectives

1. Create a searchable knowledge database.
2. Allow resource discovery by category.
3. Enable community contributions.
4. Prevent duplicate submissions.
5. Provide rich metadata.
6. Support intelligent filtering.
7. Remain fully open source.
8. Allow public browsing without registration.
9. Provide a simple onboarding experience.
10. Build a relationship-based knowledge graph.

---

## Knowledge Graph Vision

Resources must not exist as isolated entries.

Each resource may be connected through relationships such as:

- Alternative To
- Similar To
- Competitor Of
- Integrates With
- Built By
- Maintained By
- Used By
- Funded By
- Part Of
- Depends On

The relationship layer should be considered a first-class system component.
