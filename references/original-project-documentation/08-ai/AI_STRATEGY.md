# NorthStar AI Strategy

## Principle

AI should increase data quality and discovery value without becoming an unchecked source of truth.

## Candidate Uses

- Metadata extraction
- Summarization
- Classification
- Tag suggestion
- Duplicate detection
- Relationship suggestion
- Similar-resource recommendation
- Semantic search
- Resource assistant

## Human Oversight

High-impact changes should have provenance and an approval path.
