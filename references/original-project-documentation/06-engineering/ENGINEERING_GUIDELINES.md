# NorthStar Engineering Guidelines

## Code

- TypeScript-first where applicable
- Modular domain boundaries
- Explicit interfaces
- Small cohesive modules
- Avoid premature abstraction

## Backend

Organize by business capability rather than technical layer alone.

## Frontend

Build reusable accessible components and preserve bilingual support from the beginning.

## Data

Keep PostgreSQL authoritative. Derived indexes must be rebuildable.

## External Providers

Use adapters and interfaces.

## Documentation

Architectural decisions must be recorded.

## Testing

Critical business rules require automated tests.
