# NorthStar UX Strategy

## Design Direction

The owner requested a unique visual direction rather than a conventional AI/SaaS interface.

## Proposed Design Concept: Knowledge Navigation

The interface should feel like a living knowledge atlas:
- strong information hierarchy
- spatial relationship cues
- graph-inspired navigation
- editorial-quality resource cards
- restrained use of visual effects
- clear bilingual typography
- meaningful motion only where it explains relationships

Avoid:
- generic gradient-heavy AI dashboards
- excessive glassmorphism
- decorative AI imagery
- unnecessary animated backgrounds

## Primary UX Goal

A new user should understand the product within minutes without training.

## Key Experiences

- Search
- Explore
- Resource page
- Relationship exploration
- Submit
- Curate
- Collect
