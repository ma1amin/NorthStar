# NorthStar Research Plan

## Product Research

Validate:
- discovery problem severity
- current workarounds
- most valuable resource categories
- contribution motivation
- preferred discovery methods

## Competitive Research

Research:
- directories
- product discovery platforms
- alternative/comparison platforms
- curated lists
- knowledge graphs
- bookmarking products

## Technical Research

Validate:
- PostgreSQL graph workload
- dedicated graph database threshold
- search engine performance
- ingestion limits
- semantic search architecture
- AI provider economics

## Legal / Data Research

For every external source, validate:
- API availability
- terms of use
- rate limits
- attribution requirements
- scraping restrictions
- data licensing

No external-source policy is assumed in this package.
