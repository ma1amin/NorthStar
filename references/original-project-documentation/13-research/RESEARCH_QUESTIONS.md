# NorthStar Research Questions

1. What do users currently do when they remember a resource but not its name?
2. Which categories have the strongest repeated-discovery pain?
3. What makes users contribute a resource?
4. What makes users trust community metadata?
5. Which relationships are most useful in practice?
6. How often does resource metadata become stale?
7. What should the graph show first on a resource page?
8. What is the right balance between open contribution and moderation?
9. Which external sources provide the highest-value data?
10. Which monetization model preserves user trust and open-source value?
