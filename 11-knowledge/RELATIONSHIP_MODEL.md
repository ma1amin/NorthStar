# NorthStar Relationship Model

## Core Types

- Alternative To
- Similar To
- Competitor Of
- Integrates With
- Built By
- Maintained By
- Used By
- Funded By
- Part Of
- Depends On

## Relationship Attributes

- source
- target
- type
- provenance
- confidence
- status
- created_by
- created_at
- updated_at
- verification_state

Relationships should be queryable independently of the resource page.
