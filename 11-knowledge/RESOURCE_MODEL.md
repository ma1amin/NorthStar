# NorthStar Resource Model

## Resource

A resource is a discoverable digital entity with a canonical identity and structured metadata.

## Proposed Fields

- id
- canonical_url
- name
- short_description
- description
- resource_type
- category
- tags
- owner/creator where verified
- source/provenance
- status
- verification_status
- created_at
- updated_at
- last_checked_at

## Provenance

Important data should retain its origin so users and moderators can distinguish:
- user submitted
- externally sourced
- AI suggested
- moderator verified
